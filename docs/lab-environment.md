

\# Lab Environment Documentation



\## 1. Overview



This document describes the physical desktop environment used for the IT Support Hardware \& Software Troubleshooting Lab.



The practical exercises were performed on a spare desktop computer running Windows 10 Home.

\## 3. Operating System



| Property | Value |

\## 5. Diagnostic Utilities



The following built-in Windows utilities and commands were used:



| Utility | Purpose |
|---|---|
| System Information | Hardware and OS inspection |
| Task Manager | Performance and process monitoring |
| Device Manager | Device and driver inspection |
| Disk Management | Partition inspection |
| Programs and Features | Software inventory |
| Windows Update | OS update status |
| Command Prompt | Network diagnostics |
| Disk Cleanup | Cleanup opportunity assessment |
| Storage Settings | Storage usage inspection |
| Reliability Monitor | Reliability event review |
| Event Viewer | System event inspection |



\## 6. Lab Scope



The environment was used for:

\- Desktop hardware inspection

\- Windows performance monitoring

\- Startup application analysis

\- Installed software inventory

\- Driver inspection

\- Basic network troubleshooting

\- Storage and maintenance review



No enterprise server, Active Directory, or production infrastructure was part of this lab.
