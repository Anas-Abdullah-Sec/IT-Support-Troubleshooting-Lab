\## 1. Project Summary



This project demonstrates foundational IT Support skills through eight hands-on practical tasks performed on a physical Windows desktop.



The work focused on hardware inspection, system performance monitoring, startup analysis, software inventory, Windows Update inspection, device driver review, network diagnostics, and Windows maintenance assessment.



Each task was documented with technical observations and supporting screenshots.



\## 2. Project Objectives



\- Develop practical Windows desktop troubleshooting experience.

\- Understand hardware and operating system configurations.

\- Monitor system resource utilization.

\- Inspect startup applications and running processes.

\- Review installed applications and device drivers.

\- Perform basic IP connectivity and DNS diagnostics.

\- Examine disk storage and system reliability information.

\- Maintain structured technical documentation and evidence.



\## 3. Practical Work Completed



| Task | Area | Outcome |
|---|---|---|
| 01 | Hardware \& Performance Inspection | System specifications and resource usage documented |
| 02 | Startup Application Analysis | Startup entries and impact indicators reviewed |
| 03 | Process Analysis | Running processes and resource usage inspected |
| 04 | Software Inventory | Installed applications and versions recorded |
| 05 | Windows Update Inspection | OS support notification reviewed |
| 06 | Driver Inspection | Wi-Fi, Ethernet, and display drivers documented |
| 07 | Network Troubleshooting | IPv4, connectivity, and DNS tests completed |
| 08 | Disk Cleanup \& Maintenance | Storage, reliability, and event logs inspected |



\## 4. Key Technical Results



\- Successfully inspected the hardware and Windows configuration of an HP desktop.

\- Recorded CPU, memory, disk, and network utilization snapshots.

\- Reviewed startup applications without changing their configuration.

\- Documented installed software and selected driver versions.

\- Confirmed successful loopback and external IP connectivity tests.

\- Confirmed successful DNS resolution for google.com.

\- Identified the Windows 10 end-of-support notification.

\- Recorded an improper shutdown event in Reliability Monitor.

\- Identified approximately 1.19 GB of potential cleanup space through Disk Cleanup.



These results represent the observations from the actual lab activities. They do not imply that repairs or configuration changes were performed.

\## 7. Limitations



This was a foundational desktop IT Support lab.



The project did not include:

\- Enterprise Active Directory administration.

\- Windows Server administration.

\- Advanced hardware repair.

\- Production environment incident response.

\- Driver replacement or updates.

\- Software installation or uninstallation.



The project documents inspection and basic diagnostics rather than claiming advanced administration or repair experience.
